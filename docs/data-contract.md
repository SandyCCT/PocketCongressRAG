# 資料欄位規格

PocketCongressRAG 會合併同一個 Excel 活頁簿中的所有工作表。缺少必要欄位或欄位格式不符時，前處理與查詢可能失敗。

## 必要欄位

| 欄位名稱 | 型態 | 範例 | 規則 |
|---|---|---|---|
| `委員名字` | string | `王育敏` | 使用完整姓名；空值或空白會填為 `N/A`。 |
| `原本發言內容` | string | `……` | 自由文本；空值或空白會填為 `無資料`。 |
| `地區性／全國性` | string／多值 | `地區性、全國性` | 可使用 `、`、`；` 或 `／` 分隔。 |
| `所屬委員會` | string／多值 | `教育及文化委員會、交通委員會` | 可使用 `、`、`；` 或 `／` 分隔。 |
| `議題分類` | string／多值 | `高等教育、學術倫理` | 可使用 `、`、`；` 或 `／` 分隔。 |
| `日期` | Excel Date／`YYYY-MM-DD` | `2025-03-17` | 前處理後以字串存放。 |
| `會期` | string | `第11屆第1會期 (2024/2 ~ 2024/7)` | 不得留空，格式為 `第H屆第N會期 (YYYY/M ~ YYYY/M)`。 |

## 欄位允許值

`地區性／全國性`：

- `地區性`
- `全國性`

`所屬委員會`：

- `內政委員會`
- `外交及國防委員會`
- `司法及法制委員會`
- `交通委員會`
- `社會福利及衛生環境委員會`
- `財政委員會`
- `經濟委員會`
- `教育及文化委員會`

## 前處理行為

- 將 `日期` 轉為字串。
- 移除多值欄位中的換行。
- 將 `；`、`／` 正規化為 `、`，再依 `、` 分割。
- 將 `所屬委員會` 展開為 `所屬委員會1..n`。
- 將 `地區性／全國性` 展開為 `涵蓋層級1..n`。
- `原本發言內容`、`議題分類` 的空值或空白填為 `無資料`。
- 其他欄位的空值或空白填為 `N/A`。

前處理後的資料會計算 SHA-256 fingerprint。即使總筆數不變，只要索引欄位內容改變，系統仍能辨識資料版本差異。

## 檔案位置

將來源檔案放在：

```text
data/sessions/第H屆第N會期 (YYYYMM ~ YYYYMM).xlsx
```

應用程式會依使用者選擇的會期尋找對應檔案。實際執行前，請確認檔名中的屆期與活頁簿內的 `會期` 欄位一致。
